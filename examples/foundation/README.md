# 基础知识数据包

这是一个小规模、固定知识范围的学习实验数据包，用于研究“先读文本，再学问答”
能否帮助模型回答不同写法的问题。它不是通用聊天数据，也不是已训练的模型。

## 文件与用途

| 文件 | 用途 |
| --- | --- |
| `pretraining.txt` | 约10万字符的连续文本，仅此文件用于预训练 |
| `qa_train.jsonl` | 200条问答，50个知识点各4种训练问法，用于问答训练 |
| `qa_train_expanded.jsonl` | 500条问答，包含全部200条原题，每个知识点共10种训练问法 |
| `extra_train_questions.json` | 每个知识点的6条新增训练问法，仅维护问题，答案引用原定义 |
| `qa_expansion.json` | 扩充训练文件的来源、原文件校验值和新文件校验值 |
| `qa_test.jsonl` | 50条问答，每个知识点1种未见问法，只用于测试 |
| `facts.json` | 知识说明、答案与原始训练/测试问法的权威定义，不作为训练输入 |
| `sources.json` | 来源、获取时间、条目版本、截取方式与文件校验值 |
| `LICENSE.md` | 本数据包的署名及共享许可说明 |

问答仍使用当前入口支持的 `question` 和 `answer` 字段；`fact_id` 对应
`facts.json` 中的知识点，便于检查每条题的来源和训练/测试归属。

## 范围与答案

50个知识点覆盖科学、地理和算术。科学题包括物态变化、光合作用、气体分子式、
太阳系和地球运动；地理题包括首都、大洲、海洋、河流和南北半球；算术题包括
固定四则运算、平面图形、奇偶数、质数和单位换算。

温度题明确使用标准大气压下的纯水；三角形内角和题限定欧氏平面；自转时长题
限定太阳日尺度并保留近似值。氢气、氧气的分子式与元素符号明确区分。
答案采用固定短答案，不因大小写、单位或句末标点差异自动算对。

四个训练问法和一个测试问法询问相同知识、使用同一个预期答案。
扩充训练文件为每个知识点增加六种表达方式，答案仍引用 `facts.json`。
测试集评估的是有限范围内的问法迁移，不是未知知识、一般算术推理或多轮聊天。
例如训练了`3乘4`，不能据此宣称模型能计算任意乘法。

## 来源与整理

百科正文来自中文维基百科，通过其公开 MediaWiki API 获取纯文本。每个条目的
链接、当前版本编号、版本时间、作者历史链接和正文校验值记在 `sources.json`。
百科正文作者是对应条目的维基百科贡献者，完整署名历史可通过 `history_url`
查看。许可链接和修改说明见 `LICENSE.md`。

知识说明和250条题由 Model Lab 在本次准备中通过 AI 辅助编写，基础答案与条件
已核对，问答不是从网上直接复制的一批题。知识说明进入预训练文本，题目本身
不进入预训练文本。`facts.json` 包含测试题，因此不能把它当成预训练材料。

正文整理过程包括 Unicode NFC 规范化、去掉行尾空白、独立章节标题及尾部参考
资料，过滤含 LaTeX `displaystyle` 命令的段落，再轮流从不同条目选择完整段落，
达到约10万字符时停止。相同段落只取一次，不通过复制段落凑长度，也不把文章
截到半句话。百科内容包含部分进阶知识及公式的纯文本表示，不含原页面的图片；
它不等于一套小学教材，全文并未逐句完成科学审校。

水条目中包含“75%~78%”地表覆盖比例的一段与地球条目中约71%的海洋覆盖比例
不一致，未用于本快照。被剔除段落的校验值和理由记在该条目的
`excluded_paragraphs` 中。其他章节仅按公开百科来源节选，后续发现事实问题
应单独修正数据，不通过修改测试答案或隐藏错误来提高结果。

## 分集与词表

测试题在训练前固定，不得用于更新参数、选训练轮数或重新构建词表。
预训练材料包含相关事实，这是实验本身所需，不表示测试题泄漏；需要隔离的是
测试题的提问文本。训练题与测试题在去掉空格、标点后也不能相同。

词表只从 `pretraining.txt` 构建。检查问答中已有字符是否被它覆盖，不从测试集
提取新字符补回预训练文本；覆盖失败应报告未知字符，而不是偷偷换词表。
本快照的实际覆盖情况记在 `sources.json`，由离线测试验证。

## 扩充训练问法

`qa_train_expanded.jsonl` 的前200条与 `qa_train.jsonl` 一致，随后是300条新增
问法。所有50个知识点统一增加六种表达，不只对模型答错的知识点加练。
新增题由 Model Lab 通过 AI 辅助编写，按原知识定义核对条件和短答案，并沿用
本目录 `LICENSE.md` 的 CC BY-SA 4.0 许可。新增问题只在
`extra_train_questions.json` 中手工维护；生成文件不能独立修改。

扩充数据不增加知识点、答案或词表。温度、太阳日、欧氏平面等必要条件保留，
改变提问顺序、直接提问/请求回答、数字/文字表达，并加入简单情境。
例如长度问题增加“一根1米长的线有多少厘米？”，而质量与时间问题仍明确
询问克和秒，不能混用单位。

原200条题、50条测试题、预训练文本、知识定义和百科来源文件保持不变。
新训练题去掉空格和标点后不能重复，也不能与固定测试题或预训练正文重合；
所有问答字符均由原预训练词表覆盖。输入和输出校验值见 `qa_expansion.json`。
无需联网即可重新生成到新的目录：

```powershell
.venv\Scripts\python.exe -X utf8 scripts\prepare_expanded_qa.py --output-dir data\experiments\qa-expanded-copy
.venv\Scripts\python.exe -m pytest tests\test_expanded_qa.py -q
```

脚本只生成数据，不训练，也拒绝覆盖已有输出。训练方法与 `--finetune` 参数
见项目 README。后续比较时，应从相同的预训练模型、固定词表和模型结构开始，
使用独立的新 checkpoint，不覆盖原模型。更大的训练集在相同轮数下包含更多
参数更新，因此这种比较是数据扩充实验，不是等计算量对照。

固定50题可用于跟踪不同问法的回答情况，但已有结果被查看，不能再称作从未
查看的盲测集。不要把这些题加入训练或根据其成绩选择训练轮数。本数据准备
不运行模型，也不宣称新增问法已经提高答题正确率。

## 检查与重新准备

固定数据的结构、分集、词表与来源校验可以离线运行：

```powershell
.venv\Scripts\python.exe -m pytest tests\test_foundational_data.py -q
```

需要重新下载时使用新的输出目录，避免覆盖已经用于实验的数据：

```powershell
.venv\Scripts\python.exe -X utf8 scripts\prepare_foundational_data.py --proxy http://127.0.0.1:7897 --output-dir data\experiments\foundation-new
```

没有代理时省略 `--proxy`。脚本不修改系统代理，下载不需要额外 Python 依赖。
它读取固定的 `facts.json`，获取百科的当前版本；再次下载可能得到新版本，不
保证与本快照逐字相同。`sources.json` 标识每次实际下载和选择的内容，Git 保留
已经提交的固定快照。不能把新版本悄悄替换进正在比较的两个模型。

数据准备脚本不训练或评估模型。要验证预训练是否改善效果，还需
另行运行同结构、同词表、同问答训练设置的随机初始化对照模型和预训练模型。
现有训练命令、微调与续训的区别见项目 README；对照运行入口尚未实现。
