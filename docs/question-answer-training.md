# 独立问答训练

连续文本训练学习下一字符预测，适合续写文章。独立问答训练则明确告诉模型：
问题用于提供上下文，回答才是当前学习目标。两者都使用现有 Decoder-only 模型。

Answer-only Loss（仅回答损失）、Prefix（已知前缀）、Ignored Target（忽略标签）
和 Right Padding（右侧补齐）的定义见 [`glossary.md`](glossary.md)。

## 数据和样本

输入是 JSONL 文件，每行一个 JSON 对象，字段是字符串 `question` 和 `answer`。
换行由 JSON 字符串中的 `\n` 表示，不能用空行拆分一段多行回答。

```json
{"question": "水的化学式是什么？", "answer": "H2O。"}
```

`QuestionAnswerDataset` 将这一条问答展开为多个回答字符预测样本：

```text
输入：用户：水的化学式是什么？\n助手：       目标：H
输入：用户：水的化学式是什么？\n助手：H      目标：2
输入：用户：水的化学式是什么？\n助手：H2     目标：O
输入：用户：水的化学式是什么？\n助手：H2O    目标：。
```

这里的 `\n` 表示真正的换行。每个样本只读取当前问题和此前回答，不能读取未来
回答字符，也不能读取另一条问答。最后还学习两个换行，表示本条回答结束。
超过上下文长度时保留最后一段前缀，与 `generate_greedy` 的窗口裁剪规则一致。

这份可读实现每个样本只预测一个回答字符，计算效率低于一次预测多个位置的
训练方式，但它直接展示了训练输入与独立提问输入之间的对应关系。

## Loss 和批处理

输入及目标均为 `[B, T]`，其中 B 是批次大小，T 是本批最长前缀长度。每个样本
只有最后一个有效位置的目标是回答字符 ID；其他目标为 `-100`。补齐发生在右侧，
补齐目标同样为 `-100`。因果 Attention 保证有效前缀不能读取右侧补齐位置。

手写 Cross Entropy 先为真实目标取出对数概率，再只对非 `-100` 位置取平均。
`train_epoch` 也只用真实监督 Token 数加权累计 Epoch Loss。

## 运行和验收

训练及提问命令见 README 的“独立问答实验”。Checkpoint 保存数据模式、词表、
模型配置和数据指纹，继续训练时沿用保存的模式；连续文本模型仍按原模式恢复。

验收先检查训练原题能否独立回答，再另行检查未训练的问题。原题回答正确只证明
模型能记住这组问答，不证明泛化能力。不能把训练 Loss、训练原题通过率或短问答
实验结果直接当成完整聊天能力。

## 多种问法的验收

问法扩展实验使用独立的训练文件与测试文件，命令和路径见 README 的
“换一种问法的实验”。测试问题必须在训练前确定，与训练问题没有完全相同的
字符串；它们使用训练词表中已有的字符，询问相同知识点。

测试问题不会用于构建词表或更新模型参数。训练题和未见问法应分别计数，空回答、
重复内容或错误字符都不能算作正确。包含未知字符的情况应单独记录，避免把词表
覆盖和回答能力混为一谈。实验中只问“首都”而没有说明国家的题目，预期回答是
请求补充国家信息；当前单题提问入口不保留历史上下文。

## 从已有模型开始微调

Pretraining（预训练）和 Fine-tuning（微调）的定义见术语表。运行命令见 README
的“先读文本，再用问答微调”。该流程不替换模型算法：两个阶段使用同一个
Decoder-only 模型，先在连续文本上预测下一字符，再在独立问答上只学习回答。
微调也支持新的连续文本数据，不要求源模型必须来自文本模式。

微调加载全部已训练的参数，不冻结任何层；新数据决定之后的梯度更新。
Optimizer 的动量状态不从源文件继承，微调轮次也不累加预训练轮次。
当前学习率使用本次命令的值，输出文件保存微调数据的模式、范围和指纹。
之后使用 `--resume` 会恢复这份微调状态，不能偷偷换掉数据或训练模式。

词表的字符顺序决定每个 Token ID 的含义，同时决定嵌入表和输出头中的对应行。
因此不能对微调文本重新构建词表，也不能修改模型结构。微调数据中出现原词表
没有的字符时，入口明确报错，不会丢弃或替换字符。准备预训练材料时应覆盖后续
训练数据所需字符，包括问答格式中的“用户：”“助手：”和换行；不能把测试题
拼入训练材料来解决未知字符问题。旧文件没有保存词表和结构时不能作为微调起点。

`examples/pretraining_demo.txt` 是配合现有基础问答的极小流程示例，不是大规模
预训练语料。完成两阶段训练只证明模型参数能够传递并继续学习；要证明预训练
带来改善，还需要同结构、同词表、同问答训练设置的随机初始化对照模型，并在
未参与训练的问题上分别评估。当前示例不包含这种效果对照实验。
